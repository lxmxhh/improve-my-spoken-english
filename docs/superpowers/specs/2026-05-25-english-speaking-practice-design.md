# English Speaking Practice Website — Design Spec

**Date:** 2026-05-25  
**Status:** Approved  

---

## 1. Project Goal

Build a web app that helps users improve English speaking ability through daily AI-coached, script-guided conversations. The app generates structured dialogue scripts, guides the user through them line by line, evaluates spoken responses by meaning (not exact wording), and tracks daily practice streaks.

---

## 2. Core Requirements

- Daily practice sessions with an AI coach
- Each session is centered on a single topic (~5 minutes)
- Daily goal: complete at least 3 topics (~15 minutes total)
- Voice-based interaction with optional text display
- Anonymous for MVP (no login required); localStorage for persistence
- Deployed on Vercel

---

## 3. Architecture

```
Browser
├── Web Speech API (STT)       ← Free, browser-native speech recognition (en-US)
├── Web Speech Synthesis (TTS) ← Free, browser-native text-to-speech for AI lines
└── Next.js React UI           ← Session flow, progress dashboard

Next.js API Routes (Vercel)
├── POST /api/generate-script  ← Generate full conversation script for a topic
├── POST /api/evaluate-line    ← Semantic match: did user say the expected line?
└── POST /api/summarize        ← Generate end-of-session vocabulary + feedback

OpenRouter API
└── Powers all three API routes above (model-agnostic, e.g. GPT-4o, Claude, Gemini)
```

**Browser compatibility:** Chrome and Edge only (Web Speech API requirement). Show a warning banner on Firefox/Safari.

## 5. Session Flow

### 5.1 Topic Selection
- At session start, call `/api/generate-script` with a randomly chosen category
- Categories: Daily Life / Work & Career / News & Society / Entertainment & Culture
- API returns a full script (see §6) and displays 3 topic options for the user to pick

### 5.2 Pre-session Warm-up (skippable)
- AI displays 2–3 keywords from the topic to help user prepare mentally
- "Ready" button starts the conversation

### 5.3 Conversation Loop (per line)
1. Coach's line plays via TTS and is shown as subtitle text
2. User's reference line is displayed in full: *"You can say: ___{expected line}___"*
3. User presses and holds the microphone button to record
4. Recording limits:
   - Auto-stop and submit after **60 seconds**
   - If **no speech detected within 10 seconds**, cancel and prompt to retry
   - A subtle progress bar shows the 60-second countdown during recording
5. On release (or auto-stop), speech is sent to `/api/evaluate-line`
6. Evaluation result:
   - ✅ **Pass** → brief positive indicator, advance to next line
   - ❌ **Fail** → "Try again" prompt, allow one retry
   - ❌ **Fail again** → mark line as failed, coach advances to next line automatically

### 5.4 End-of-Session Summary
Triggered when all script lines are complete or the 5-minute timer expires.

- Call `/api/summarize` to generate:
  - 3–5 new vocabulary words from the conversation
  - 1–2 grammar tips (phrased positively: *"Try saying '...' next time"*)
  - One personalized encouragement line
- Display pass rate: e.g. "You nailed 8 out of 10 lines!"
- Buttons: **[Start Next Topic]** or **[That's Enough for Today]**

### 5.5 Daily Goal Tracking
- After completing 3 sessions in one day → celebration animation + streak +1
- Progress indicator on home page: 🟩🟩⬜ (2/3 topics done today)

## 6. Script Format

Generated by `/api/generate-script`. Each script is a JSON array of turns:

```ts
interface ScriptTurn {
  speaker: "coach" | "user"
  text: string          // Full line text
  // For user turns only:
  hint?: string         // The reference line shown to user (same as text for option A)
}

interface Script {
  topic: string         // e.g. "Morning Routine"
  category: string      // e.g. "Daily Life"
  turns: ScriptTurn[]   // Alternating coach/user, typically 10–16 turns total
}
```

Example prompt for script generation:
```
Generate a natural spoken English conversation between an encouraging coach named Alex
and a B1-B2 level learner on the topic: "{topic}".
The conversation should last about 5 minutes when spoken aloud (~10-14 exchanges).
Return valid JSON matching this schema: { topic, category, turns: [{speaker, text}] }.
Coach lines should be 1-3 sentences. User lines should be 1-2 sentences, conversational.
```

## 7. AI Coach Prompt Design

### Script Generation (`/api/generate-script`)
See §6 above.

### Line Evaluation (`/api/evaluate-line`)
Lightweight semantic comparison — returns only `yes` or `no`:

```
Expected line: "{expected}"
User said: "{actual}"
Did the user express the same core meaning? Reply with only: yes or no
```

### Session Summary (`/api/summarize`)
```
Here is a conversation script the user just practiced:
{script as text}

The user passed {n} out of {total} lines.

Generate a brief end-of-session summary with:
1. 3-5 vocabulary words from this conversation worth remembering (with simple definitions)
2. 1-2 gentle grammar tips based on common mistakes for this level
3. One encouraging closing sentence

Reply in plain text, not JSON.
```

## 8. Data Model (localStorage)

```ts
interface Session {
  id: string            // uuid
  date: string          // "2026-05-25"
  topic: string         // "Morning Routine"
  category: string      // "Daily Life"
  durationSec: number   // actual seconds practiced
  totalLines: number    // total user turns in script
  passedLines: number   // lines passed on first or second attempt
  failedLines: number   // lines failed on both attempts
  summary: string       // raw text from /api/summarize
  completedAt: string   // ISO timestamp
}

interface DailyRecord {
  date: string          // "2026-05-25"
  sessionIds: string[]  // completed session ids for this day
  goalMet: boolean      // true when sessionIds.length >= 3
  streakDay: number     // current streak count (cached for quick read)
}
```

**localStorage keys:**
- `esp_sessions` → `Session[]`
- `esp_daily` → `DailyRecord[]`
- `esp_streak` → `number`

## 9. Error Handling

| Scenario | Handling |
|---|---|
| Browser doesn't support Web Speech API | Persistent warning banner: "Please use Chrome or Edge for voice features" |
| Microphone permission denied | Modal with step-by-step instructions to enable mic access |
| 60-second recording timeout | Auto-submit whatever was recognized; if empty, treat as no-speech |
| 10 seconds of silence | Cancel recording, show "No speech detected — tap to try again" |
| OpenRouter API error (any route) | Show inline error toast; session continues with degraded behavior (skip evaluation, mark line as passed) |
| Script generation failure | Fall back to 5 hardcoded scripts (one per category) bundled in the app |

## 10. Tech Stack

| Layer | Choice |
|---|---|
| Framework | Next.js 14 (App Router) |
